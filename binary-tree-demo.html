教材 §3.5.1 二叉树的概念

🌳 生活中的树形结构

族谱、公司组织架构、计算机文件目录、网页DOM树……

它们都不是线性的"一对一"关系，而是分支的、层次的关系 — 这就是树形结构。

📐 基本术语速览

节点 — 树中的每个数据元素
度 — 节点的子树个数，树的最大度即"树的度"
根节点 — 最顶层，唯一没有双亲的节点
叶节点 — 度为0，没有子树的终端节点
深度 — 节点的最大层次数
双亲/孩子/兄弟 — 节点间的关系

二叉树：度≤2的有序树

每个节点最多两棵子树，左右次序不可颠倒

(b) 左子树

访问根 → 遍历左子树 → 遍历右子树

算法步骤

  1. 若二叉树为空，则空操作返回
  2. 否则：① 访问根节点
  3. ② 先根序遍历左子树
  4. ③ 先根序遍历右子树

遍历序列

中根序遍历 · 左根右

遍历左子树 → 访问根 → 遍历右子树

算法步骤

  1. 若二叉树为空，则空操作返回
  2. 否则：① 中根序遍历左子树
  3. ② 访问根节点
  4. ③ 中根序遍历右子树

遍历序列

a + b * c / d

后根序遍历 · 左右根

遍历左子树 → 遍历右子树 → 访问根

算法步骤

  1. 若二叉树为空，则空操作返回
  2. 否则：① 后根序遍历左子树
  3. ② 后根序遍历右子树
  4. ③ 访问根节点

遍历序列 · 后缀表达式（逆波兰式）

a b + c d / *

三种遍历 · 对比总结

同一棵树，不同的访问次序，不同的应用场景

🔵 先根序

根 → 左 → 右
* + a b / c d
前缀表达式（波兰式）
用于：复制树结构、表达式解析
口诀：遇根就访问

🟡 中根序

左 → 根 → 右
a + b * c / d
中缀表达式
就是我们日常书写的算式！
口诀：左完再取根

🟠 后根序

左 → 右 → 根
a b + c d / *
后缀表达式（逆波兰式）
计算机求值表达式就用这个！
口诀：左右走完再拿根
