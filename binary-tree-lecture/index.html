3.5.1 二叉树的概念

树形结构的基本术语

图 3.5.3 树形结构示意图（每个节点标注度）

🔵 节点度 (Degree)

节点度：节点拥有的子树个数。图中：A度=2，B度=2，C度=1，D/E/F/G/H度=0。
树的度：所有节点度的最大值。图中树的度=2。
度的分类：度=0→叶节点（D/E/F/G/H）；度=1→单分支节点（C）；度=2→双分支节点（A/B）。二叉树中每个节点度≤2。

🟠 双亲·孩子·兄弟

B和C是A的孩子，A是B和C的双亲。B和C互为兄弟。
层次：根在第1层，子节点逐层+1。深度：此树共4层，深度=4。
根节点是唯一没有双亲的节点；叶节点是没有孩子的节点（度为0）。

🟢 核心认识：树形结构是描述层次关系的数学模型。与线性结构（一对一）不同，树形结构表达一对多的关系。二叉树是其中最基础、最重要的一种——每个节点最多两个子树，且左右有序。

3.5.1 二叉树的概念

二叉树的定义

📖 递归定义

二叉树是 n (n≥0) 个节点的有限集：
① n=0 时，为空树
② n>0 时，由一个根节点及两棵互不相交的、分别称为左子树和右子树的二叉树构成

⚡ 两个核心特点

特点一：每个节点最多两棵子树（度 ≤ 2）。
特点二：子树有左右之分，次序不可颠倒。

关键理解：二叉树的定义是递归的——左子树和右子树本身也是二叉树。这种"自己定义自己"的结构，正是递归算法能优雅处理二叉树的根本原因。

3.5.2 二叉树的基本操作

什么是二叉树的遍历？

遍历（Traversal）：从根节点出发，按照某种次序依次访问二叉树中所有节点，每个节点仅被访问一次。

🔄 遍历需完成的三项工作

① 访问根节点
② 遍历左子树
③ 遍历右子树

规定"先左后右"，根节点的访问时机决定三种遍历方式。

📐 三种遍历方式

先根序：根 → 左 → 右
中根序：左 → 根 → 右
后根序：左 → 右 → 根

为什么遍历是基础？ 二叉树的查找、插入、删除等操作，本质上都是在遍历过程中完成的。掌握了遍历，就掌握了二叉树操作的核心。

递归的"魔法":调用栈如何工作

🌲 示例树 + 当前访问位置

橙色填充 = 当前正在访问

📚 调用栈状态(栈底→栈顶)

—— 空栈 ——

每访问一个节点,压栈(push);访问完子树后,弹栈(pop)

看懂这张图 = 看懂递归:遍历 `*` 时把 `*` 压栈,递归去遍历 `+`,把 `+` 也压栈 → 处理完 `+` 的左子树后,`+` 弹栈 → 回到 `*` 继续遍历右子树……系统帮我们记着"我刚才走到哪",这就是"调用栈"的本质作用。
讲解时强调:1) 递归是"函数自己调用自己";2) 每次调用都在栈上开一格;3) 子调用结束就弹栈,父调用继续。可以用手指比划"压栈→压栈→处理→弹栈→继续"的过程,学生更容易理解。

关键洞察

三种遍历 → 三种表达式
这是二叉树从"数据结构"到"编译原理"的桥梁。

应用深入

表达式二叉树：遍历即求值

算术表达式可以唯一地表示为一棵二叉树：运算符在非叶节点，操作数在叶节点。不同的遍历方式，恰好对应三种表达式书写形式。

🔵 先根序 → 前缀表达式

* + a b / c d

也称为波兰式。运算符写在操作数之前。
Lisp等函数式语言采用这种形式：
(* (+ a b) (/ c d))

🟢 后根序 → 后缀表达式

a b + c d / *

也称为逆波兰式（RPN）。
计算机求值表达式的标准方式！
不需要括号，不需要优先级规则，只需一个栈。

实际应用：你的计算器APP、编程语言的编译器，都在用后缀表达式来计算数学表达式。二叉树的遍历，是连接"人类书写方式"和"机器计算方式"的桥梁。
可以现场演示：给表达式 (a+b)*(c-d)，让同学们画出二叉树并做三种遍历。帮助理解"同一棵树，三种视角"。

🎯 三种游览顺序

先根序（A→B→D→E→F→C→G→H→I）：
🦒出入口 → 🦁狮子 → 🐯老虎 → 🦅老鹰 → 🦓斑马(F) → 🐘大象 → 🦏犀牛 → 🐎马(H) → 🐧企鹅

中根序（E→D→B→F→A→H→G→C→I）：
🦅老鹰 → 🐯老虎 → 🦁狮子 → 🦓斑马(F) → 🦒出入口 → 🐎马(H) → 🦏犀牛 → 🐘大象 → 🐧企鹅

后根序（E→D→F→B→H→G→I→C→A）：
🦅老鹰 → 🐯老虎 → 🦓斑马(F) → 🦁狮子 → 🐎马(H) → 🦏犀牛 → 🐧企鹅 → 🐘大象 → 🦒出入口

计算思维：将现实世界的结构关系映射为数据模型（二叉树），再用算法（遍历）求解——这就是计算思维的核心过程。三种遍历给出了三种不同的游览体验，这正是算法服务于实际需求的体现。

练习一 · 找出二叉树

根据二叉树的定义（每个节点最多两棵子树，且左右有序），判断下面哪些是二叉树？

A. 根有左子树、右子树，左子节点还有一个右子节点 B. 根有两棵子树，各有两个子节点——标准的满二叉树 C. 根节点下面接了三个子节点 D. 根只有右子树，右子树根又有左右子树

提示：回忆二叉树的两个核心特点——度≤2 且 左右有序。

答案：A、B、D 是二叉树，C 不是——C 的根节点有3个子节点，度超过2，违反二叉树定义。

练习二 · 3个节点的二叉树

某二叉树有3个节点。两位同学争执不下：
一人认为形态如右图(a)，另一人认为形态如右图(b)。

你赞同谁？3个节点的二叉树一共有多少种不同的形态？请画出所有形态。

(a) 根+左+右

(b) 根→右→右

提示：注意左右子树的区分！形态(a)和(b)都合法。想想还有哪些？（答案是5种）

答案：两人都正确！3个节点的二叉树共有5种不同形态：① 根+左子树+右子树（各1节点）② 根→左→左 ③ 根→左→右 ④ 根→右→左 ⑤ 根→右→右。注意左右有序——根→左→左 和 根→右→右 是不同形态。

以下三个方向可以帮助你建立更完整的数据结构知识体系——

🔷 拓展一：层序遍历（广度优先 BFS）

除了先根序、中根序、后根序这三种深度优先遍历，二叉树还有层序遍历——从上到下、从左到右逐层访问。如同"剥洋葱"：先第1层，再第2层，再第3层……
例如：表达式树 *+ab/cd 的层序结果为 * + / a b c d

🔶 拓展二：二叉搜索树（BST）简介

二叉搜索树是一种特殊的二叉树，满足：左子树所有节点 < 根 < 右子树所有节点。对它进行中根序遍历，就能得到一个升序序列！这就是为什么BST常用于快速查找——每次比较可以排除一半数据。
