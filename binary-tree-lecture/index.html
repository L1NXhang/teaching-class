3.5.1 二叉树的概念

树形结构的基本术语

🔵 节点 (Node) 与 度 (Degree)

树的每个数据元素称为节点。
节点拥有的子树个数称为该节点的度。
树中所有节点的度的最大值称为树的度。

例：若一棵树中，节点A有2棵子树，节点B有3棵子树，其他节点都≤2，则树的度为3。

🎯 根节点、叶节点与内部节点

根节点：树中最顶层、唯一没有双亲的节点。
叶节点：度为0的节点，也称终端节点。
内部节点：除根以外的分支节点。

👨‍👩‍👦 双亲、孩子与兄弟

某节点的子树的根称为该节点的孩子；
该节点称为其孩子的双亲；
同一双亲的孩子之间互称兄弟。

📏 层次、深度与高度

根为第1层，孩子逐层+1。
若某节点在第L层，其孩子就在第L+1层。
深度/高度：树中节点的最大层次数。

3.5.1 二叉树的概念

二叉树的定义

📖 递归定义

二叉树是 n (n≥0) 个节点的有限集：
① n=0 时，为空树
② n>0 时，由一个根节点及两棵互不相交的、分别称为左子树和右子树的二叉树构成

⚡ 两个核心特点

特点一：每个节点最多两棵子树（度 ≤ 2）。没有子树或只有一棵子树都是允许的。
特点二：子树有左右之分，次序不可颠倒。即使只有一棵子树，也必须明确是左子树还是右子树。

关键理解：二叉树的定义是递归的——左子树和右子树本身也是二叉树。这种"自己定义自己"的结构，正是递归算法能优雅处理二叉树的根本原因。

3.5.1 二叉树的概念

四种基本形态 · 满二叉树 · 完全二叉树

▸ 四种基本形态（非空二叉树）

(a) 仅根节点

(b) 仅左子树

(c) 仅右子树

(d) 左右子树都有

▸ 满二叉树 vs 完全二叉树

满二叉树

每一层的节点数都达到最大值
所有叶节点在同一层
每个分支节点都有左右子树
深度为k的满二叉树有 2ᵏ−1 个节点

→

完全二叉树

对满二叉树从上到下、同层从左到右编号
按从大到小的顺序连续删除若干节点
剩下的就是完全二叉树
满二叉树是完全二叉树的特例

3.5.2 二叉树的基本操作

什么是二叉树的遍历？

遍历（Traversal）：从根节点出发，按照某种次序依次访问二叉树中所有节点，每个节点仅被访问一次。

🔄 遍历需要完成三项工作

① 访问根节点
② 遍历左子树
③ 遍历右子树

如果规定"先左后右"，那么根节点的访问时机就决定了三种遍历方式。

📐 三种遍历方式

先根序：根 → 左 → 右
中根序：左 → 根 → 右
后根序：左 → 右 → 根

为什么遍历是基础？ 二叉树的查找、插入、删除等操作，本质上都是在遍历过程中完成的。掌握了遍历，就掌握了二叉树操作的核心。

算法步骤（递归）

三种遍历的命名：

遍历总结

三种遍历对比 · 同一棵树，三种视角

遍历方式次序序列结果表达式类型应用场景
先根序根→左→右* + a b / c d前缀式（波兰式）复制树结构、表达式解析
中根序左→根→右a + b * c / d中缀式（日常算式）输出排序序列（BST）

关键洞察

三种遍历 → 三种表达式
这是二叉树从"数据结构"到"编译原理"的桥梁。

应用深入

表达式二叉树：遍历即求值

算术表达式可以唯一地表示为一棵二叉树：运算符在非叶节点，操作数在叶节点。不同的遍历方式，恰好对应了三种表达式书写形式。

🔵 先根序 → 前缀表达式

* + a b / c d

也称为波兰式。运算符写在操作数之前。
Lisp等函数式语言采用这种形式：
(* (+ a b) (/ c d))

🟢 后根序 → 后缀表达式

a b + c d / *

也称为逆波兰式（RPN）。
计算机求值表达式的标准方式！
不需要括号，不需要优先级规则，只需一个栈。

实际应用：你的计算器APP、编程语言的编译器，都在用后缀表达式来计算数学表达式。二叉树的遍历，是连接"人类书写方式"和"机器计算方式"的桥梁。
可以现场演示一下：给同学们一个表达式，让他们画出二叉树，然后分别做三种遍历。例如：(a+b)*(c-d) 或者更复杂的 (3+4)*(5-2)/7。这会帮助大家理解"同一棵树，三种视角"的深刻含义。

实际问题建模：游览动物园

某动物园有9个馆舍，馆舍之间有8条道路，出入口在长颈鹿馆处。
问题：如何规划一条能将每个馆舍都游遍，且每个馆舍仅游览一次的路线？

📐 建模步骤

① 将馆舍抽象为节点
② 将道路抽象为边
③ 将动物园分布图表示为二叉树

🎯 三种游览顺序

先根序：入口→先深入→出口
中根序：左区→入口→右区
后根序：由远及近返回入口
每种顺序对应不同的游览体验！
