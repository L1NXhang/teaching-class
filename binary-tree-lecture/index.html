3.5.1 二叉树的概念

二叉树的定义

📖 递归定义

二叉树是 n (n≥0) 个节点的有限集：
① n=0 时，为空树
② n>0 时，由一个根节点及两棵互不相交的、分别称为左子树和右子树的二叉树构成

⚡ 两个核心特点

特点一：每个节点最多两棵子树（度 ≤ 2）。
特点二：子树有左右之分，次序不可颠倒。

关键理解：二叉树的定义是递归的——左子树和右子树本身也是二叉树。这种"自己定义自己"的结构，正是递归算法能优雅处理二叉树的根本原因。

3.5.2 二叉树的基本操作

什么是二叉树的遍历？

遍历（Traversal）：从根节点出发，按照某种次序依次访问二叉树中所有节点，每个节点仅被访问一次。

🔄 遍历需完成的三项工作

① 访问根节点
② 遍历左子树
③ 遍历右子树

规定"先左后右"，根节点的访问时机决定三种遍历方式。

📐 三种遍历方式

先根序：根 → 左 → 右
中根序：左 → 根 → 右
后根序：左 → 右 → 根

为什么遍历是基础？ 二叉树的查找、插入、删除等操作，本质上都是在遍历过程中完成的。掌握了遍历，就掌握了二叉树操作的核心。

遍历总结

三种遍历对比 · 同一棵树，三种视角

遍历方式次序序列结果表达式类型应用场景
先根序根→左→右* + a b / c d前缀式（波兰式）复制树结构、表达式解析
中根序左→根→右a + b * c / d中缀式（日常算式）输出排序序列（BST）

关键洞察

三种遍历 → 三种表达式
这是二叉树从"数据结构"到"编译原理"的桥梁。

应用深入

表达式二叉树：遍历即求值

算术表达式可以唯一地表示为一棵二叉树：运算符在非叶节点，操作数在叶节点。不同的遍历方式，恰好对应三种表达式书写形式。

🔵 先根序 → 前缀表达式

* + a b / c d

也称为波兰式。运算符写在操作数之前。
Lisp等函数式语言采用这种形式：
(* (+ a b) (/ c d))

🟢 后根序 → 后缀表达式

a b + c d / *

也称为逆波兰式（RPN）。
计算机求值表达式的标准方式！
不需要括号，不需要优先级规则，只需一个栈。

实际应用：你的计算器APP、编程语言的编译器，都在用后缀表达式来计算数学表达式。二叉树的遍历，是连接"人类书写方式"和"机器计算方式"的桥梁。
可以现场演示：给表达式 (a+b)*(c-d)，让同学们画出二叉树并做三种遍历。帮助理解"同一棵树，三种视角"。

中根序（E→D→B→F→A→H→G→C→I）：
🦅老鹰 → 🐯老虎 → 🦁狮子 → 🐎马(F) → 🦒出入口 → 🐎马(H) → 🦏犀牛 → 🐘大象 → 🐧企鹅

后根序（E→D→F→B→H→G→I→C→A）：
🦅老鹰 → 🐯老虎 → 🐎马(F) → 🦁狮子 → 🐎马(H) → 🦏犀牛 → 🐧企鹅 → 🐘大象 → 🦒出入口
