引入

从"行当分支"到树形结构

🎭
体验探索：生、旦、净、丑是京剧四大行当。每个行当下有若干分支——例如"生"分老生、小生、武生；"旦"分青衣、花旦、老旦、武旦。
🔗
线性结构（线性表、栈、队列、字符串）只能表达一对一的关系。
🌳
树形结构可以表达一对多的层次关系——族谱、组织架构、文件目录、数的分类……

3.5.1 二叉树的概念

术语

树形结构的基本术语

🔵

节点 (Node)

树中的每个数据元素，包含数据值和指向子树的分支。

📏

度 (Degree)

节点拥有的子树个数。度为0的节点称为叶节点（终端节点）。

🎯

根节点 (Root)

树中最顶层、唯一没有双亲的节点。一棵非空树有且仅有一个根。

📐

深度/高度

树中节点的最大层次数。根为第1层，孩子逐层+1。

3.5.1 二叉树的概念

定义

二叉树的定义与特点

📖 递归定义

二叉树是 n（n≥0）个节点的有限集。
n=0 时为空树；n>0 时：
① 有且仅有一个根节点
② 其余节点分为两个互不相交的有限集，分别称为左子树和右子树

⚡ 两个核心特点

1. 每个节点最多两棵子树（度 ≤ 2）
2. 子树有左右之分，次序不可颠倒
即使只有一棵子树，也须明确是左还是右。

3.5.2 二叉树的基本操作

遍历

什么是二叉树的遍历？

📖 定义

遍历指从根节点出发，按某种次序依次访问二叉树中的所有节点，且每个节点仅被访问一次。

完成遍历的三项工作：
① 访问根节点   ② 遍历左子树   ③ 遍历右子树

如果规定"先左后右"，则根节点的访问时机决定了三种遍历方式：
先根序（根→左→右） · 中根序（左→根→右） · 后根序（左→右→根）

遍历算法详解

先根序

先根序遍历 · 根 → 左 → 右

算法步骤（递归）

  1. 若二叉树为空，则空操作返回
  2. 否则：① 访问根节点
  3. ② 先根序遍历左子树
  4. ③ 先根序遍历右子树
遍历序列（前缀表达式/波兰式）
* + a b / c d

遍历算法详解

中根序

中根序遍历 · 左 → 根 → 右

算法步骤（递归）

  1. 若二叉树为空，则空操作返回
  2. 否则：① 中根序遍历左子树
  3. ② 访问根节点
  4. ③ 中根序遍历右子树
遍历序列（中缀表达式 — 日常书写算式！）
a + b * c / d

遍历算法详解

后根序

后根序遍历 · 左 → 右 → 根

算法步骤（递归）

  1. 若二叉树为空，则空操作返回
  2. 否则：① 后根序遍历左子树
  3. ② 后根序遍历右子树
  4. ③ 访问根节点
遍历序列（后缀表达式/逆波兰式 — 计算机求值用的！）
a b + c d / *

遍历总结

对比

三种遍历 · 对比总结

遍历方式 次序 序列结果 表达式类型 应用场景
先根序 根→左→右 * + a b / c d 前缀表达式（波兰式） 复制树结构、表达式解析
中根序 左→根→右 a + b * c / d 中缀表达式 日常书写的算式！
后根序 左→右→根 a b + c d / * 后缀表达式（逆波兰式） 计算机表达式求值

🟠
